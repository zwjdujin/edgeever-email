# EdgeEver 邮件提醒 (edgeever-email)

到点自动发通知邮件的提醒中心。扫描全部笔记中的**待办任务**与**笔记提醒字段**，时间一到就通过 SMTP 把提醒发到你的邮箱。任务数据仍是普通 Markdown，本插件不做任何修改。

## 功能

- **待办提醒**：兼容 [edgeever-tasks](https://github.com/tianma-if/edgeever-tasks) 语法，`- [ ] 写发布公告 [due:: 2026-09-10]` 到期自动发邮件
- **笔记提醒**：任意笔记正文写 `[remind:: 2026-09-20 09:00]`，到点发邮件（内容为笔记标题）
- **SMTP 发信**：465 SSL / 587 STARTTLS / AUTH LOGIN，纯 JS 实现，无需额外依赖
- **防垃圾箱**：默认发件人 = 收件人 = 自己（自发自收）
- **不重发**：已发送记录存入专用笔记本的状态笔记，重启 EdgeEver 不会重复发送
- **补发机制**：EdgeEver 没开着错过的时间点，24 小时内自动补发（标题带「补发」），更早的不再打扰
- **提醒面板**：查看已到期未发、未来 14 天、已过期、最近发送记录
- **测试邮件**：一键验证 SMTP 配置

## 安装

1. 在插件市场搜索「邮件提醒」，或粘贴仓库地址安装
2. 启用插件后，从插件菜单运行「打开邮件提醒面板」

## 配置 SMTP（必做）

在插件设置中填写：

| 设置项 | 说明 | 示例 |
|---|---|---|
| SMTP 服务器 | 邮箱服务商的 SMTP 地址 | `smtp.qq.com` |
| SMTP 端口 | SSL 用 465，STARTTLS 用 587 | `465` |
| 加密方式 | `ssl` / `starttls` / `none` | `ssl` |
| SMTP 账号 | 你的邮箱地址 | `me@qq.com` |
| SMTP 授权码 | 邮箱设置里生成的**授权码**，不是登录密码 | `abcdefgh` |
| 发件人 / 收件人 | 留空 = 发给自己 | — |

常见邮箱预置：

| 邮箱 | 服务器 | 端口/加密 |
|---|---|---|
| QQ 邮箱 | smtp.qq.com | 465 / ssl |
| 163 邮箱 | smtp.163.com | 465 / ssl（授权码需勾选 IMAP/SMTP 服务） |
| Gmail | smtp.gmail.com | 465 / ssl（应用专用密码） |
| Outlook | smtp.office365.com | 587 / starttls |

> **为什么建议自发自收？** 收件人与发件人是同一地址时，大部分邮件服务商视为个人备忘而非营销邮件，进垃圾箱的概率显著降低。配置好后先发一封**测试邮件**，若进了垃圾箱，把它标记为「非垃圾邮件」即可。

### 发送通道二选一

1. **SMTP 直连**（默认）：插件环境可访问 Node 套接字（多数桌面端）时自动使用，无需其他软件。
2. **本地中转**：若测试邮件报「插件沙箱不支持直连 SMTP」，在本机运行零依赖中转脚本：

   ```bash
   node relay/server.mjs          # 可选：PORT=8787 TOKEN=xxx node relay/server.mjs
   ```

   然后在插件设置「本地中转地址」填 `http://127.0.0.1:8787`（设置了 TOKEN 时需自行代理加头，或留空 TOKEN）。中转只监听 127.0.0.1，不暴露到局域网。

## 设置提醒

### 待办任务（edgeever-tasks 语法）

在任意笔记的待办清单行上加日期字段：

```markdown
- [ ] 写发布公告 [due:: 2026-09-10]
- [ ] 下午开会 [due:: 2026-09-10 14:30]
- [/] 审阅文案 [scheduled:: 2026-09-11]
- [ ] 交房租 [due:: 2026-10-01] [priority:: highest]
- [x] 已完成（不会再提醒）  [-] 已取消（不会再提醒）
```

- 只写日期时（`[due:: 2026-09-10]`），在设置里的「**待办提醒时刻**」（默认 08:30）发送
- 行内带时间时（`[due:: 2026-09-10 14:30]`），按该时间精确发送
- 日期字段优先级：`due` > `scheduled` > `start`
- 「**待办提前量**」设置可提前 N 分钟发送（仅对待办生效，笔记提醒按填写时间精确发送）
- 重复任务：完成一条 `every day` 等重复待办后，edgeever-tasks 会把下一次日期写回笔记，本插件扫描到新日期后自动提醒下一天，无需额外配置

### 笔记提醒

在笔记正文任意**非待办行**写：

```markdown
[remind:: 2026-09-20 09:00]
```

- 日期 + 时间（空格分隔），24 小时制
- 一篇笔记取第一个 `remind::` 字段；到点发送一封以笔记标题为主题的邮件
- 只写日期不写时间时，按「待办提醒时刻」发送
- 命令菜单里有「**在光标处插入提醒字段**」可快速插入（默认 1 小时后，手工改成目标时间）

## 面板与命令

| 命令 | 说明 |
|---|---|
| 打开邮件提醒面板 | 已到期未发送 / 未来 14 天 / 已过期 / 最近发送 |
| 发送测试邮件 | 验证 SMTP 配置 |
| 立即扫描并发送到期提醒 | 不等下一个扫描周期 |
| 在光标处插入提醒字段 | 快捷写入 `[remind:: …]` |

## 工作原理

```
笔记（Markdown）→ 扫描器（每 60 秒，增量缓存，只重读变更笔记）
  → 到期队列 → SMTP 发送（直连或本地中转）
  → 已发送记录（状态笔记，自动维护）→ 重启不重发
```

- 已发送记录保存在「EdgeEver 邮件提醒」笔记本下的一篇状态笔记里（自动创建，**请勿手工编辑**），保留 14 天
- 提醒连续发送失败 3 次后停止重试（如授权码错误），修正配置后可点「立即扫描」重试
- EdgeEver 必须处于运行状态才会发信；本插件不依赖 edgeever-tasks 插件，仅语法兼容

## 隐私

- SMTP 账号与授权码仅保存在 EdgeEver 插件设置中，只用于向你自己配置的 SMTP 服务器发信
- 本地中转只监听 127.0.0.1；插件不向任何第三方服务发送数据
